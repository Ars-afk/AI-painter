# Угадай рисунок

## Описание сайта
### Кисти
**На выбор предоставлены 3 вида кисти:**
1. Карандаш
2. Маркер
3. Спрей

**После выбора кисти можно будет выбрать размер шрифта и его цвет.**
### Фон
Если вы хотите сделать свой фон, то его надо загрузить с помощью кнопки `Выберите файл` на сайте.
### Стикеры
На выбор присутствуют 4 стикера:
`Улыбка`, `Звёздочка`, `Сердечко` и `Булавка`.
### Функции
**На сайте придложены 5 функций:**
* Начать игру
`Вы начинаете игру где вам предстоит нарисовать заданный рисунок а ИИ должен его угадать.`
* ИИ рисует
`Вы меняетесь ролями с ИИ.`
* Проверить ответ
`Вы проверяете свой ответ и получаете балл в зависимости от правильности.`
* Очистить
`Вы очищаете поле рисовки.`
* Сохранить в PNG
`Вы сохраняете ваш рисунок к вам на компьютер.`
